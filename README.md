# 灵感发散器

输入一个关键词或短语，生成一张有六条分支的动态灵感图。可以围绕同一主题换一批想法，也可以选中一条灵感，沿着它继续探索。

[在线使用灵感发散器](https://inspiration-studio-duzhe.supplebeak6.chatgpt.site)，无需登录。

## 怎么用

1. 输入一个关键词或短语，例如「城市漫游」，点击 **开始发散**。页面会收起大标题，把输入框和 **换一批** 放在分支图上方。
2. 点选图上的分支。桌面端在右侧显示详情，手机端在底部显示标题和操作按钮，点击 **展开详情** 可阅读完整描述。
3. 点 **继续发散**，选中的分支会沿连线移到中央，并展开下一层。点图上方路径里的主题，可返回前面的分支。
4. 想围绕当前主题找更多想法，点 **换一批**。喜欢的灵感可以点星标收藏，再到右上角的 **已收藏** 查看。收藏保存在当前浏览器。
