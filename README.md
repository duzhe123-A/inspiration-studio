# 灵感发散器

输入任意关键词，把它展开成一张可以拖动和缩放的灵感图。每条分支都可以继续展开，之前探索过的想法会留在同一张图上。

[在线使用灵感发散器](https://inspiration-studio-duzhe.supplebeak6.chatgpt.site)，无需登录。

## 怎么用

1. 打开网页可以直接试用「超级个体」示例。在底部输入自己的关键词，或点输入框下方的提示词，再提交开启新图。点 **换一组**，会随机换成四个来自不同主题的词。点击输入框旁的 **＋**，可以把新关键词接到当前节点。
2. 点任意圆形节点，它会成为黄色中心并展开下一层。想继续探索同一个中心，点 **换一批** 追加新分支。拖动空白处平移画布，用滚轮、双指或 **＋／−** 缩放，点 **全图** 找回所有节点。
3. 点 **详情**，可以查看描述、收藏或复制。复制内容包括标题、描述和完整发散路径；收藏保存在当前浏览器。
4. 右键图上的灵感，或者点选后按 **加入方案**，可以在左上角收集 2–8 条灵感。点 **整合方案** 查看已选灵感并生成，结果可一键复制。
5. 启用 AI 后，方案会融合所选灵感，写清每步做法、所需材料、阶段成果和最终交付物。未配置 AI 或服务暂时不可用时，可以生成规则版。
6. 点右上角 **重新开始**，再点 **确认清空**，即可清空当前图和待整合灵感。提交新关键词前，可点 **撤销清空** 恢复它们。已收藏的灵感会保留。

## 部署 AI 整合

运行 `node scripts/build-site.mjs` 生成 Sites Worker。在 Sites 的运行环境配置密钥 `OPENAI_API_KEY`，并应用 `drizzle/` 下的 D1 迁移。公开站点无需登录，每日 AI 请求上限默认 50 次，可通过 `AI_PLAN_DAILY_LIMIT` 调整。
