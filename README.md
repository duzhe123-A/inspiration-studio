# 灵感发散器

输入一个关键词或短语，生成一张有六条分支的动态灵感图。可以围绕同一主题换一批想法，也可以选中一条灵感，沿着它继续探索。

[在线使用灵感发散器](https://inspiration-studio-duzhe.supplebeak6.chatgpt.site)，无需登录。

## 怎么用

1. 输入一个关键词或短语，例如「城市漫游」，点击 **开始发散**。页面会收起大标题，把输入框和 **换一批** 放在分支图上方。
2. 点选图上的分支。桌面端在右侧显示详情，手机端在底部显示标题和操作按钮，点击 **展开详情** 可阅读完整描述。
3. 点 **继续发散**，也可以在电脑上双击分支。下一层会给出可以动手尝试的点子。点 **全图** 可以查看这次展开过的分支并跳回任一节点。
4. 点 **复制灵感**，可以把当前点子的标题、描述和完整发散路径一起复制。喜欢的灵感也可以点星标，在 **已收藏** 查看。收藏保存在当前浏览器。
5. 想围绕当前主题找更多想法，点 **换一批**。
6. 点 **整合方案**，勾选 2–8 条灵感。切换分支后可以接着选。启用 AI 后，点 **AI 生成方案**，会把所选点子和路径整理成一个创意，写清每步做法、所需材料、阶段成果和最终交付物。方案可以一键复制。AI 暂时不可用时，可以生成规则版。

## 部署 AI 整合

运行 `node scripts/build-site.mjs` 生成 Sites Worker。在 Sites 的运行环境配置密钥 `OPENAI_API_KEY`，并应用 `drizzle/` 下的 D1 迁移。公开站点无需登录，每日 AI 请求上限默认 50 次，可通过 `AI_PLAN_DAILY_LIMIT` 调整。未配置密钥时，仍可在浏览器生成规则版。
